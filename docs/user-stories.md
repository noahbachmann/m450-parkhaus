damit ich **verschiedene Zeiten** stoppen kann.

damit ich weiss ob der **Countdown läuft oder abgelaufen** ist.

damit ich den **Countdown neu starten** kann.

Als **Nutzer** möchte ich die **Leuchte blinken sehen**,
damit ich weiss wann der **Countdown fertig** ist.
